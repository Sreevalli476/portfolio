About This Portfolio

This portfolio was built as a single-page, fully responsive website to present my profile, skills and project work in one place.

🛠 Tech Stack

  • Semantic HTML5 for structure
  • CSS3 with custom properties (variables) for theming, Flexbox & CSS Grid for layout
  • Vanilla JavaScript for the dark/light theme toggle
  • Google Fonts (Poppins + Inter) for typography
  • Fully self-contained — no external frameworks required to run

✨ Features

  • Responsive layout — adapts from mobile to desktop
  • Light/dark theme support (auto + manual toggle)
  • Smooth-scroll navigation between sections
  • Direct links to all social/coding profiles and project repositories
  • Clear "In Progress" labeling for work still under development
